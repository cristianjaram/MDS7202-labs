# MDS7202 - Laboratorios

Repositorio asociado a las entregas semanales del ramo **Laboratorio de Programación Científica de Ciencia de Datos (MDS7202)** perteneciente a un curso obligatorio del Magíster en Ciencia de Datos de la Universidad de Chile.

👥 Colaboradores: Felipe Fierro y Cristian Jara
📅 Semestre: Primavera 2025  
📁 Estructura: 

- `/labs`: en esta carpeta tendremos el desarrollo de todos los laboratorios.
- `/labs/lab{n}/data`: intentaremos seguir este formato para poder guardar la data y añadir un path consistente al gitignore cada vez.
- `/resources`: aqui dejaremos material de clases útil para el desarrollo de laboratorios y así tenerlo a mano.
